# Leet Me Out

A little app that forces you to practice LeetCode. Because apparently "I'll do it tomorrow" isn't a study plan.

Open it, get a random problem, and give your brain a rep. Pick another question or redo an old favorite — practice is practice.

- **Show up:** optional reminders when you sign in or wake your computer.
- **Lock in:** focus mode stays maximized and on top until you earn a fresh Accepted. Yes, Two Sum counts again.
- **Need an escape?** Use your custom shortcut and password to allow closing. Forgot the password? Ten wrong attempts (even blank ones) let you out. We're encouraging habits, not running a prison.

Focus mode remembers your commitment when you reopen the app. Solving lets you close it; turning focus mode off takes a solved problem and your password.

Windows first. macOS is on the wish list. Current installers are unsigned previews.

One problem. Then freedom.

*Not affiliated with LeetCode. Just very invested in your next Accepted.*

## Get it

Download the Windows installer from [GitHub Releases](https://github.com/xjjjack/leet-me-out/releases), or build it yourself from source below. Pick your adventure; both end with LeetCode.

### Build it yourself

Requires Node.js 22.12 or newer.

```sh
npm install
npm start
```

`npm test` runs the checks. `npm run dist` builds an installer.
